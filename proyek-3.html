Website Portofolio Statis

Proyek pengembangan antarmuka web modern berbasis HTML5 dan CSS3 murni.

HTML5 CSS3 JavaScript

Tentang Proyek

Website ini adalah portofolio digital pribadi saya yang dirancang dengan tema "Dark Minimalist". Proyek ini dibangun sepenuhnya dari nol tanpa menggunakan framework CSS eksternal. Tujuannya adalah untuk menguasai fundamental web modern, mengatur tata letak melayang (floating card) yang responsif, serta menjaga kebersihan kode (clean code) secara efisien.

Fitur Utama & Arsitektur

Meskipun berstatus sebagai website statis, proyek ini mengimplementasikan logika JavaScript untuk memberikan pengalaman pengguna tingkat lanjut:

  • Single Page Application (SPA): Mencegah reload browser secara penuh saat navigasi halaman menggunakan vanilla JS.
  • Audio Latar Kontinu: Memanfaatkan localStorage untuk melacak status pemutaran musik agar tidak terpotong saat berpindah halaman.
  • Optimasi UI/UX: Transisi warna dan animasi hover yang halus menggunakan CSS murni untuk menjaga performa web tetap ringan.
